# Delta Convergence: demo video script

**Status:** draft v2, revised after the review-council dry run and two decisions from the decision owner (B13 naming, B14 knowledge-work act). Written before the build is finished. Revise after M4 (resolve + promote) and again after M6 (ship). It is final only when it matches what the deployed console actually does on recording day.
**Target runtime:** 6:50 (the contest allows 5 to 10 minutes; the council target was about 6:30 to 7:00).
**Format:** screen recording with voiceover. Narrator and face cam are still open (PRD §13, item 4).

## Naming rule (B13)

Say and show "Delta Convergence" every time: narration, on-screen text, titles, captions and copy. Never "Delta" alone. Internal identifiers (`refs/notes/delta`, `delta-core`) are fine when they appear as code on screen; do not read them aloud as the product name.

## Honesty legend

Every segment carries one of these labels. The label appears on screen as a small corner tag whenever it isn't LIVE.

| Label | Meaning |
|---|---|
| **LIVE** | A real run recorded on the day: real agents on the models shown on screen, the deployed Worker, real Artifacts forks. Long agent runs may be sped up; if so, a "4x" tag and a wall-clock overlay are on screen. |
| **SEEDED** | Synthetic data generated by a fixture, with no model behind it. Always tagged "seeded" on screen. |
| **REPLAY** | A recorded event log re-driven through the same engine. Always tagged "replay" on screen. |
| **GRAPHIC** | Illustration or title card. Not a recording of the product. |

If a live step fails and a fallback goes in, change the on-screen tag and the narration to match. Never present replay as live.
